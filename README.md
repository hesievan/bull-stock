# A股牛市热度指数

> 每日更新的量化工具，从 **4 个维度、16 个核心指标 + CFFEX 股指期权恐慌指数** 综合评估 A 股市场整体热度水平，
> 并对 **沪深 300 / 创业板 / 科创 50 / 北证 50 / 中证 A500 / 中证 1000 / 中证红利** 七大核心指数
> 单独输出牛市见顶预判信号，同时追踪 **银行 / 非银金融 / 食品饮料 / 医药生物 / 电力设备 / 电子 / 有色金属 / 公用事业 / 房地产 / 煤炭**（申万一级 10 行业）+ **白酒 / 保险**（二级细分），共 12 个重点行业的板块热度。
>
> **定位：仅提示离场 / 减仓，不发出进场或加仓信号。**

>
> **结论**: V2 指标体系擅长"极端区域预警"和"领先于市场的趋势反转提示"。极热区是可靠的减仓信号（后 60 日 −7.4%，75% 下跌），极冷区是可靠的建仓信号（后 60 日 +7.9%，62% 上涨）。
>
> **门禁对比（P0-P3 逐步升级）**：基线（P0 前，13 指标）区分度 15.3 / 同期 0.810 / 领先 −0.231 / 极热后 −8.3% / 极冷后 +7.5%；P1 补三指标后区分度 14.6；P2 滚动分位后 15.5；P3 扩至 16 指标后 **15.0 / 0.816 / −0.230 / −7.4% / +7.9%** —— 全流程不退化，且同期相关与极冷信号收益有所改善。

## 指标体系

### V2 引擎（每日流水线所用）

| 维度 | 权重 | 子指标 | 权重 | 说明 | 方向 |
|------|------|-------|------|------|------|
| **估值** | 28% | 大盘 PE 分位 | 14% | 全市场 PE 中位数滚动分位（含成分股数量过滤） | 越高越贵 |
| | | 巴菲特指标 | 14% | A 股总市值 ÷ 年度 GDP（GDP 缺失时取最近可用） | 越高越贵 |
| **资金** | 15% | 两融余额市值比 | 5% | (融资+融券)÷流通市值（85% 分位起饱和收敛） | 越高越热 |
| | | 国债期限利差 10Y-2Y | 3% | 实证牛市期利差偏低（曲线走平），方向翻转（低利差=宽松=高分） | 低→高分 |
| | | M1-M2 剪刀差 | 3% | M1 同比 − M2 同比（货币活化） | 越高越热 |
| | | 南向净买额 | 1% | 南向通当日净买额（跨境资金活跃度） | 越高越热 |
| | | 融资买入占比 | 3% | 融资买入额 ÷ 两市成交额（杠杆激进程度） | 越高越热 |
| **情绪** | 35% | 涨停封板率 | 6% | 收盘涨停数÷盘中触板数（本地计算，stock_daily OHLC 自连接前日收盘价） | 越高越热 |
| | | 成交额 M2 比 | 14% | 日成交额 ÷ M2 | 越高越热 |
| | | 换手率 | 9% | 成交额÷流通市值×10（10 年窗口预计算表） | 越高越热 |
| | | IF 基差率 | 2% | (IF 主力−沪深300)÷现货（升水=机构乐观） | 越高越热 |
| | | 振幅热度 | 2% | 沪深300 日内(高−低)÷昨收（多空博弈激烈度） | 越高越热 |
| | | 已实现波动率 | 2% | 沪深300 20 日对数收益 std×√250（**替代 iVIX 期权隐波**） | 低→高分 |
| **结构** | 22% | 创新高占比 | 12% | 250 日新高股票占比（含顶背离惩罚） | 越高越好 |
| | | MA 排列比 | 6% | MA20>MA60>MA120 占比 | 越高越好 |
| | | 涨跌家数广度 | 4% | 上涨家数÷下跌家数（普涨/普跌宽度） | 越高越好 |

> **换手率口径**：引擎与 `daily_turnover` 表存的换手率原始值为**百分比数值**（如 2.33 即 2.33%），与 tushare 全市场基准（约 3%）量级一致。显示层统一按百分比数值展示。
>
> **百分位口径（P2.1）**：所有指标统一使用**滚动窗口分位** —— 只取最近 1260 个交易日（≈5 年）计算历史百分位（`v2_engine.percentile.rolling_window: 1260`，环境变量 `HEAT_PCT_WINDOW` 可覆盖；序列短于窗口时退化为全历史）。相比全历史分位，滚动窗口对市场结构性变化（regime drift）更敏感，牛熊参考系随市场更新。
>
> **iVIX 替代决策（P3）**：roadmap 原列 iVIX（上证50ETF 期权隐含波动率）因免费数据源不稳定未接入；以**现货已实现波动率**（沪深300 20 日对数收益 std×√250）替代进分，同属"波动率越低=越贪婪"的负向逻辑，数据源稳定（index_daily 本地可算），回测已验证不退化。如需真 iVIX 可后续以 akshare `option_risk_indicator_sse` 补充（作为展示性指标，不进分）。

**展示不计分（3 项）**:

1. **恐慌指数**（CFFEX 股指期权隐含波动率）: 0.3 × 上证50隐波 + 0.4 × 沪深300隐波 + 0.3 × 中证1000隐波（数据源: optbbs.com 中金所 QVIX；含三品种成分值 + 集中度）。历史极值参考: 2024-02 微盘危机 26.3（橙区）、2024-10 政策脉冲 41.7（红区）；正常区间: 绿 <20 / 黄 20-25 / 橙 25-30 / 红 >30。
2. **新增投资者开户数**（月度，中国结算）: 散户 FOMO 低频锚，仅展示不入分（月频不硬塞日频合成）。数据源 `stock_account_statistics_em` 自 2023-08 后停止更新，展示时附月份标签。前端概览页低频锚行展示"新增开户 99.6万户 (2023-08)"。
3. **宽基 ETF 总份额**（日度快照）: 16 只宽基 ETF 份额合计（亿份）。份额历史无法免费回填，自 2026-09-01 起每日积累，待历史 ≥180 日后再评估入分。前端概览页低频锚行展示"宽基ETF份额 2448亿份"。

### 评分合成路径

```
原始数据 → 预计算表(口径统一) → 滚动窗口 1260 日百分位 (0-100)
        → 指标按权重加权合成综合分 → 3 日平滑 → 四区间分类 + 市态标签
```

### 背离惩罚

- **情绪背离**: 高换手率 + 指数下跌 → 情绪得分扣减最多 20 分
- **新高顶背离**: 指数涨 + 新高占比下降且 < 30% → 结构分扣减最多 15 分

## 市态标签

引擎输出 `regime` 字段（`compute_regime`），按综合分与结构健康度将市场划分为四种市态，前端概览页以徽标展示：

| 市态 | 判定 | 含义 |
|------|------|------|
| 🔴 过热 | 综合分 ≥65 且结构分偏高 | 全面亢奋，减仓信号密集 |
| 🟡 分歧 | 综合分 40–64 | 多空胶着，结构性机会 |
| 🔵 修复 | 综合分 <40 且趋势转好 | 从冰点回暖，观察期 |
| 🟢 冰点 | 综合分 <40 且结构低迷 | 极度冷淡，历史底部区域 |

> 当结构维度出现**破位风险**（如创新高占比骤降、MA 排列转空）时，徽标附加"破位风险"标记（红色）。

### 运维增强（P0-P3）

- **`.env` 集中加载**：所有脚本统一通过 `src/config.load_dotenv_safe()` 读取 `TUSHARE_TOKEN`/`FEISHU_WEBHOOK` 等密钥，环境变量优先、文件回退。
- **配置强类型与校验**：`load_config_typed()` 返回 dataclass 视图；加载时校验 16 指标权重求和≈1.0、热度等级完整性（YAML 为唯一事实源，代码 `DEFAULT_WEIGHTS` 与其 assert 一致）。
- **滚动窗口分位**：`v2_engine.percentile.rolling_window: 1260`（≈5 年）统一作用于全部指标（P2.1）。
- **Lighthouse CI 门禁（P0.3）**：`.github/workflows/daily.yml` 含 lighthouse job，`lighthouserc.json` 定义性能/可访问性/最佳实践/SEO 四类阈值，不合格 CI 失败。
- **前端性能（P0.2）**：ECharts 按需定制构建 `web/echarts.custom.min.js`（650KB vs 全量 1.0MB），`defer` 加载 + 首屏/懒加载拆分，首屏数据量减少约 1MB。
- **结构化日志（可选）**：`run_daily` 支持 `HEAT_LOG_JSON=1` 输出单行 JSON 日志；默认文本格式。
- **备份清理**：`python scripts/db_tools.py cleanup [--keep N] [--days D] [--dry-run]` 清理过期 gzip 备份与 `.bak_*` 临时备份。
- **耗时与进度**：`run_daily` 每步带序号进度与耗时；`backtest_v2`/`backfill_*` 用 `src/common.timed` 记录总耗时。
