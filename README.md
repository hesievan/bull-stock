# A股牛市热度指数

> 每日更新的量化工具。计算引擎（v3.0）每日计算 **16 个市场指标**，其中 **9 个计分键** 按权重合成 0–100 的综合热度分，
> 用于预判 A 股整体过热程度；并对 **沪深 300 / 创业板 / 科创 50 / 北证 50 / 中证 A500 / 中证 1000 / 中证红利** 七大核心指数
> 单独输出牛市见顶预判信号，同时追踪 **银行 / 非银金融 / 食品饮料 / 医药生物 / 电力设备 / 电子 / 有色金属 / 公用事业 / 房地产 / 煤炭**（申万一级 10 行业）+ **白酒 / 保险**（二级细分），共 12 个重点行业的板块热度。
>
> **定位：仅提示离场 / 减仓，不发出进场或加仓信号。**

## 项目说明

**这是什么**：一套跑在 GitHub Actions 上的 A 股整体热度监测系统。每个交易日自动抓取行情 / 估值 / 资金 / 宏观数据入库（SQLite），由 v3.0 引擎计算综合热度分并生成 JSON + 网页仪表盘（GitHub Pages），极值时通过飞书 / Bark 推送。

**核心思路**：市场在"过热"状态下，未来 60 日的风险收益比显著变差。因此所有指标都设计为**反向指标**——热度分越高，代表市场越接近历史意义上的顶部区域。这一点已由全历史回测验证（见[判断逻辑与回测验证](#判断逻辑与回测验证)）：综合分与未来 60 日收益的 Spearman IC 为 **−0.21**（9 键全部为负），且热度档位对后续收益**严格单调**。

**引擎版本脉络**：v2.x（16 指标 4 维度加权）→ M1.4/M1.5 计分收敛（16→9，移出 7 键仅展示）→ **v3.0 方向修正**（3 个资金键方向翻转 + pe/turnover 回退去趋势，依据 `reports/方向体检_M2a.md`）→ M2b-3 `engine_mode` 配置化（single9 / single6 双档）。README 所述口径均以 **v3.0 + single9（默认）** 为准。

## 热度区间

综合热度分 0–100，切点由 `config/*.yaml` 的 `heat_levels` 块统一驱动（引擎 / JSON 输出 / 前端 / 推送同源，无硬编码）：

| 颜色 | 分数 | 含义 | 行动建议 | 后 60 日实证（回测） |
|------|------|------|---------|---------------------|
| 🟢 绿色安全 | 0–39 | 估值偏低，情绪冷淡 | 安全区间 | +3.19%（胜率 60.7%） |
| 🟡 黄色警惕 | 40–54 | 部分指标偏高 | 需关注 | +1.47%（胜率 53.1%） |
| 🟠 橙色关注 | 55–64 | 多项指标偏高 | 考虑减仓 | −1.08%（胜率 46.6%） |
| 🔴 红色预警 | 65–100 | 多项指标历史高位 | 考虑离场 | −2.09%（胜率 43.1%） |

**极值叠加档**（不改变上述连续四档 label，仅用于极值信号 / 强提示判定）：

| 信号 | 判定 | 后 60 日实证 |
|------|------|-------------|
| 🔥 极热 `extreme_hot` | 综合分 ≥ 80 | **−8.60%（胜率仅 15.3%）**——全回测最强减仓信号 |
| 🧊 冰点 `extreme_cold` | 综合分 ≤ 29 | 绿档下沿，历史底部区域 |

收紧到 ≥75 时：后 60 日 −4.71%、胜率 31.2%（n=186）。极热 / 极冷触发时飞书 / Bark 推送（`notify_on: ["extreme", "hot"]`）。

### engine_mode：single9（默认）vs single6

`engine_mode` 是计分键集合开关（M2b-3），解析顺序：**环境变量 `HEAT_ENGINE_MODE` > config `v2_engine.mode` > 默认 single9**。

| 模式 | 计分键 | 全样本 IC60 | seg2 (2023-26) | 近 2 年 |
|------|--------|------------|----------------|---------|
| **single9**（默认） | 9 键全用 | −0.2123 | −0.1813 | −0.5657 |
| **single6**（防御档） | 剔除 turnover / ma_alignment / new_high 后重归一 | **−0.2590** | **−0.3494** | **−0.6181** |

- **single6 的价值**：2023-26 市场结构漂移后，上述 3 键在牛内动量化（IC 转正 +0.05~+0.67）、熊内与 pe/buffett 冗余；剔除后剩余 6 键均为"估值 / 资金 / 反转拐点"驱动，反指逻辑更自洽。增益全部来自 seg2（Δ−0.168）与近 2 年（Δ−0.052，牛市段 Δ−0.084）；代价是 seg0/seg1 历史区轻微受损（+0.02~+0.05，已过去的历史）。
- **single6 不是微调**：36.3% 的交易日展示档位会迁移（red 档 17.9%→15.0% 更"纯"，green 档 35.0%→37.0% 更"实"）。
- **默认保持 single9**（与已发布 history.json 口径连续）；若前向数据（发布后 6-12 个月）确认 single6 稳定更优，可 flip 默认。切换方式：

```bash
HEAT_ENGINE_MODE=single6 python scripts/run_daily.py    # 环境变量
# 或 config/*.yaml → v2_engine.mode: single6
```

## 核心指标定义

引擎每日计算 **16 个指标**（全部输出用于展示与趋势图），其中 **9 个计分键** 参与综合分合成（M1.4/M1.5 收敛，依附录 A + 出口判据）。权重表由 `config/*.yaml` 的 `v2_engine.weights` 驱动（YAML 为唯一事实源，`assert Σw=1.0`），代码内置 `DEFAULT_WEIGHTS` 仅作防漂移基准。

### 9 个计分键（single9 权重，Σ=1.0）

| 计分键 | 权重 | 维度 | 口径 | 方向（高分含义） |
|--------|------|------|------|------------------|
| 大盘 PE 分位 | 21.2% | 估值 | 全市场 PE 中位数 10 年滚动分位（n_stocks ±50% 过滤 + 绝对下限 450）；**v3.0 D2 回退去趋势，用原始分位**（raw IC60 −0.116 vs 去趋势 −0.003，去趋势抹掉"绝对贵贱"信号） | 越高越贵 |
| 巴菲特指标 | 21.2% | 估值 | A 股总市值 ÷ 前一年度 GDP，10 年滚动分位 | 越高越贵 |
| 创新高占比 | 18.2% | 结构 | 250 日新高股票占比（2% 容差），10 年滚动分位 | 越高越热 |
| 换手率 | 13.6% | 情绪 | 成交额÷流通市值×10，10 年窗口；**v3.0 D3 回退去趋势**（raw seg0/1 −0.384/−0.339 vs det −0.266/−0.115） | 越高越热 |
| MA 排列比 | 9.1% | 结构 | MA20>MA60>MA120 占比；**唯一保留去趋势**（÷750 日滚动中位数后取分位，对抗 2023-26 中枢抬升） | 越高越好 |
| 国债期限利差 10Y-2Y | 4.5% | 资金 | 10Y−2Y 国债收益率；**v3.0 D1 翻转**：利差越**高**（曲线走陡/紧缩预期）→ 分越高（实证原方向 IC60 +0.137 为顺周期动量，与热度假设相反） | 高利差→高分 |
| M1-M2 剪刀差 | 4.5% | 资金 | M1 同比 − M2 同比（月频）；**v3.0 D1 翻转**：剪刀差越**低**（资金活化不足）→ 分越高 | 低剪刀差→高分 |
| 融资买入占比 | 4.5% | 资金 | 融资买入额 ÷ 两市成交额（流量杠杆）；**v3.0 D1 翻转**：占比越**低**（杠杆萎缩）→ 分越高 | 低占比→高分 |
| IF 基差率 | 3.0% | 情绪 | (IF 主力收盘−沪深300 现货)÷现货；升水=机构乐观=高分 | 升水→高分 |

按维度聚合的权重占比：估值 42.4% / 结构 27.3% / 情绪 16.7% / 资金 13.6%（由 9 键权重归一得出，非独立配置）。

### 计算并展示、但不再计分的 7 个指标（M1.4/M1.5 移出）

| 指标 | 口径 | 移出原因 |
|------|------|---------|
| 两融余额市值比 | (融资+融券)÷流通市值（85% 分位起饱和收敛） | 降级为风险修饰，M2 待恢复共振逻辑 |
| 涨跌家数广度 | 上涨÷下跌家数比 | 与结构维度信息重叠 |
| 成交额 M2 比 | 日成交额÷M2 | 与换手率冗余（r=0.972） |
| 涨停封板率 | 封板数÷触板数（stock_daily OHLC 本地计算） | IC≈0，区分度最低 |
| 已实现波动率 | 沪深300 20 日对数收益 std×√250（替代 iVIX） | 样本外反转 |
| 振幅热度 | 沪深300 (高−低)÷昨收 | 回测无正向贡献，弃用 |
| 南向净买额 | 南向通当日净买额（北向 2024-08 停披后的接棒指标） | 口径污染，待重构后回归 |

### 不计分展示项（3 项）

1. **恐慌指数 QVIX**（CFFEX 股指期权隐波，optbbs.com）：0.3×上证50 + 0.4×沪深300 + 0.3×中证1000，含三品种成分值 + 集中度。历史极值：2024-02 微盘危机 26.3、2024-10 政策脉冲 41.7。
2. **新增投资者开户数**（月度，中国结算）：散户 FOMO 低频锚。数据源自 2023-08 后停止更新，展示时附月份标签。
3. **宽基 ETF 总份额**（16 只合计，日快照）：份额历史无法免费回填，自 2026-09-01 起逐日积累，待 ≥180 日后评估入分。

### 百分位与去趋势口径

- **滚动窗口分位（P2.1）**：全部指标只取最近 **1260 个交易日（≈5 年）** 计算历史百分位（`v2_engine.percentile.rolling_window`，env `HEAT_PCT_WINDOW` 可覆盖），对 regime drift 更敏感。
- **月频序列**：M1-M2 剪刀差 / 成交额 M2 比按 **60 个月**窗口取分位（修 1260 交易日窗口与月频错配的静默退化）。
- **去趋势（M1.3）**：原始值 ÷ 自身 750 日滚动中位数（shift 1）后再取分位。v3.0 后仅 **ma_alignment** 保留（pe/turnover 已实证回退）。
- **评分合成路径**：

```
原始数据 → 预计算表(口径统一) → 滚动窗口百分位 (0-100)
        → 9 计分键按权重加权(行重归一, 缺键自适应) → 综合分
        → 背离惩罚 → 四区间分类 + 市态标签 + 极值信号
```

## 市态标签与背离惩罚

引擎输出 `regime` 字段（`compute_regime`），切点与 `heat_levels` 连续四档同源：

| 市态 | 判定 | 含义 |
|------|------|------|
| 🔴 过热 | 综合分 ≥ 65 | 全面亢奋，减仓信号密集 |
| 🟠 分歧 | 综合分 55–64 | 多空胶着，部分指标已偏高 |
| 🟡 修复 | 综合分 40–54 | 从低位回暖，观察期 |
| 🟢 冰点 | 综合分 < 40 | 冷淡，历史底部区域 |

叠加字段：

- **极值信号**：`extreme_hot`（≥80）/ `extreme_cold`（≤29），见[热度区间](#热度区间)。
- **结构破位风险** `structure_break_risk`：结构维度分 < 30 **且** 上证近 20 日跌幅 < −3% → True（MA 排列 / 新高占比双弱 + 指数技术性破位）。

**背离惩罚**（防止"高位放量下跌"被误判为健康）：

| 类型 | 触发条件 | 惩罚 |
|------|---------|------|
| 情绪背离 | 换手率分 > 70 且上证 20 日跌 > 1.5% | 换手率分扣 20 分 |
| 新高顶背离 | 上证 20 日涨 > 3% 且新高占比下降 > 5% 且当前 < 30% | 新高占比分扣 15 分 |

### 运维增强

- **`.env` 集中加载**：所有脚本统一通过 `src/config.load_dotenv_safe()` 读取 `TUSHARE_TOKEN`/`FEISHU_WEBHOOK` 等密钥，环境变量优先、文件回退。

- **engine_mode 全链路同构**：引擎 `compute_index_v2` → `json_writer` → `backtest_v2 --mode` → `refill_history_v2` 注入点统一，未来扩展 singleN 只需增加 `SINGLE*_DROP_KEYS`。
- **Lighthouse CI 门禁**：`daily.yml` 含 lighthouse job，`lighthouserc.json` 定义性能/可访问性/最佳实践/SEO 四类阈值，不合格 CI 失败。
- **前端性能**：ECharts 按需定制构建（650KB vs 全量 1.0MB），`defer` + 首屏/懒加载拆分。
- **结构化日志（可选）**：`HEAT_LOG_JSON=1` 输出单行 JSON 日志；默认文本格式。
- **备份清理**：`python scripts/db_tools.py cleanup [--keep N] [--bak-keep K] [--days D] [--dry-run]` 清理过期 gzip 备份与 `.bak_*` 临时备份。
- **依赖锁定**：`pyproject.toml` 单一来源 + `uv.lock` 多平台 sha256 哈希（CI `uv sync --frozen`，杜绝版本漂移；依赖含平台 marker 分支，单平台 requirements 锁不可用）。

## 注意事项

1. **定位边界**：本指数仅提示离场 / 减仓时点风险，**不发出进场信号**；绿档 +3.19% 的实证是"低风险区统计特征"，不构成买入建议。
2. **预测力口径**：IC60 为 60 日维度信号，IC20（−0.09）显示短期（周级别）区分力有限——不要用日级波动解读分数。
3. **低频数据滞后**：M1/M2 为月频（次月中旬公布）、GDP 为年度、开户数源已停更（2023-08）——低频锚展示时附月份标签，引擎内部按"最近可用值"对齐，不引入前视。
4. **已知盲区**：缩量阴跌型顶部（如 2018-01，热度仅 37.8）预警不足；2023-26 结构漂移区信号最弱（seg2 IC60 −0.18），如担心可切 `single6` 防御档。
5. **北向资金不可用**：港交所 2024-08-19 起停止披露北向净买入额，该指标已退役；跨境信号观察南向净买额（当前仅展示）。
6. **历史数据边界**：股票日线自 2015 年起，更早区间无数据；`indicator_history.json` 个别早期日期因成交额缺失缺 turnover 类指标。
7. **数据时区与休市**：流水线按交易日运行（工作日 18:00 北京时），法定节假日不产出新数据；前端展示"最近交易日"口径。
8. **engine_mode 切换即口径变化**：single6 与 single9 有 36.3% 交易日档位迁移，切换前阅读[回测验证](#engine_modesingle9默认vs-single6)一节，勿在生产频繁切换。
